# vk 13.0 · 机制优先

> 这份文件是 v13 的**冻结规格**。它取代 `design.md` 里与之冲突的部分（尤其 §1 观看条件的推演、§11 没有动效）。
> 一句话：**库只负责“画面里的物”，不负责“这一集怎么讲”。**

## 0 · 身份

一个视频制作环节里的**画面原语层**。它不决定讲什么、不决定怎么排、不决定节奏；
它保证：**任何一帧里出现的物，都在正确的时刻、以正确的姿态、被正确地测量。**

判断一条改动该不该进库，只问三个问题：

1. 它是不是**所有画面都成立**的？（只对这一集成立 → 不进）
2. 它是不是**值或行为**？（“这一帧该怎么构图” → 不进，那是作者的事）
3. 它能不能被**测量**？（不能测量 → 先想清楚怎么量，再加）

## 1 · 四层

| 层 | 内容 | 谁写 |
|---|---|---|
| **值 tokens** | 尺度梯、间距角色、线宽、明度面、色相、行高、缓动、时基 | 库作者；作者不直接碰 |
| **原语 primitives** | 盒、文字、图、线、面 —— 不含语义 | 作者需要时直接用 |
| **机制 mechanisms** | 七套跨原语的规则（见 §2） | 作者用属性调用 |
| **预设 presets** | 源码窗、终端、文件树、字节表、内存格、指标、图窗… | 作者日常主要写这一层 |

**预设纪律**：预设只能使用——① token 层的值；② 机制层的行为。
不许硬编码任何数值、颜色、间距、字号。违反这条，预设会重新裂成 39 个方言。

## 2 · 七套机制

| # | 机制 | 回答什么 | 今天的对应 |
|---|---|---|---|
| M1 | **体量 Mass** | 一个物能占多大、多重 | 字阶 + 组件 min-height，散落各处 |
| M2 | **映射 Mapping** | 数据 → 位置/长度/亮度/刻度 | 只有 `vk-bars` 内建一维 |
| M3 | **路由 Routing** | 两点之间的关系与方向 | `vk-edge` 雏形，坐标仍需手算 |
| M4 | **场与层 Field/Layer** | 满幅的底、叠在面上的物、挖出来看的一块 | `vk-page-bleed`（只能整幅）、`elevation` |
| M5 | **姿态 Pose** | 现在讲这里 / 其余退后 / 标注 / 编号 | 13 种写法，互不知情 |
| M6 | **求值 Seek** | 时刻 → 姿态 | 无 |
| M7 | **文本 Text** | 断行、行宽、标点、孤行、中英混排 | 全靠浏览器默认 |

## 3 · 姿态：两轴，一个 region

`act` 只管动作，`strength` 只管响度，`tone` 只管颜色，`state` 只留 `ok / warn / err`。

| act | 语义 | 唯一配方 |
|---|---|---|
| `focus` | 现在讲这里 | 行：16% 钴蓝底 + 4px 左条；块：2px 钴蓝外框；数：钴蓝 ink |
| `context` | 其余退后 | 非祖先链兄弟 `opacity` 降到 `dim`（默认 0.28）；**不画白幕、不画描边** |
| `mark` | 作者标注 | 石墨下划线 / 石墨框 / 石墨 8% 底；**永不用钴蓝** |
| `trace` | 关系与方向 | 2px 石墨线 + 箭头；可 draw-on |
| `badge` | 编号批注 | 石墨气泡 + 引线 + n；一帧 ≤2 |
| `compare` | 对照 | split / wipe；增删只用语义色 |

- **一个 focus 是一个 region**：5 个高亮字节、两行表格都只算 1 个。
- **焦点预算**：attack 120ms / release 200ms，交接时 `w_out = 1 - w_in`，任意时刻 `Σw ≤ 1`。
- **`vk-spotlight` 与 `vk-ring` 不再是两个原语**：spotlight = `act="context"` 的实现，ring = `act="focus"` 的形状。
- 旧词退役：`current` / `state="current"` / `tone="focus"` → 保留一版别名，构建期给迁移警告。

## 4 · 求值：时间不在组件里

- 组件只承诺「任一稳定姿态成立」；求值器把作者的声明折算成姿态。
- 作者写：`at`（秒）/ `enter`（rise·fade·scale·wipe·draw·type·count）/ `stagger` / `hold` / `poster`。
- `seek(t)` 是**纯函数**：先 reset 再按绝对状态重算，结果只取决于 t，与到达路径无关。
- 只动 `transform / opacity / clip-path / stroke-dashoffset`；**绝不改布局属性**。
- `poster`（默认 t=end）必须逐像素等于“不带动画的静态页”。
- 不提供播放器、不提供转场、不提供时间轴 UI。
- 构建产物里不允许出现 `animation:` / `transition:`。

## 5 · 输出契约

```
vk shot scene.html --at 2.4 --out frame@2.4.png     # 单帧
vk shot scene.html --fps 30 --range 0-4.6 --out-dir film/09   # 帧序列
vk shot scene.html --scene --out scenes/09.json     # 时间表
```

时间表 = 每个 cue 的 `{ t0, dur, ease, target, pose, props }`。下游（剪辑 / Remotion / ffmpeg）按表合成，帧就是成品。
**库不碰编码、帧率合成、音画同步。**

## 6 · 观看条件与尺度

1080p 出片，观众在手机横屏看：真实缩放 **0.36–0.40**（高度受限），设计按 **0.38**。

| 角色 | 设计 px | @0.38 | 用途 |
|---|---|---|---|
| 标签 / 行号 / 刻度 | **36** | 13.7 | 不读第二遍的字 |
| 代码 / 表格 / 地址 | **40** | 15.2 | 等宽数据 |
| 正文 | **48** | 18.2 | 要读懂的内容 |
| 小标题 / 眉题 | **96** | 36.5 | — |
| 页标题 | **144** | 54.7 | 单行上限实测 93.6% 宽 |
| 数字主角 | **224** | 85 | 一帧一个 |
| 一个词当家 | **320** | 122 | 满幅 |

规矩：

- **小字到标题是 2.0× 断层**；相邻档比 ≥1.4（今天的 1.23–1.375 是“看起来一样大”的数学原因）。
- 36 是地板，且只给“不读第二遍”的字；必须读懂的一律 ≥48。
- 线宽只有两档：**发丝 2px、结构 4px**（1px 在 0.38× 下 = 0.38 CSS px，等于不存在）。
- 字重反过来用：≤40 用 **500**，≥144 用 **600**（700 在大字上又黑又土）。
- 一帧容量：正文 12 行 / 代码 15 行（今天 5 行）。
- 组件必须具备 **compact / normal / hero** 三档内在尺寸（内距、行高、内部字号随之变）。

## 7 · 门禁

`vk check` 出两级：`✗`（硬失败，影响退出码）与 `△`（提醒）。

- **硬**：本层语义——焦点唯一（或显式 `focus="none"`）、region 计数、姿态面积预算、错锚点、字号地板、安全区、数字格式自洽、预设不得硬编码值。
- **软**：编排判断——主角面积、字号断层、连续帧骨架重复、体量曲线、底部空带、留白。
- 跨帧报告（`--series`）输出：每帧的墨量 / 面 / 主角面积 / 骨架签名 / 焦点面积 / 字阶分布 / 白占比 / 重心。

## 8 · 十条决定（来源：2026-10-30 的十轮问答）

1. 单位是**镜头**，可彻底重构，39 个标签不神圣。
2. 库**不排片**：不求解版式、不出帧型、不规定节奏。
3. 时间在求值器，组件只出姿态。
4. 注意力只有一套词汇（act × strength）。
5. 身份是**机制优先**，形状降为预设。
6. 门禁**分层**：语义硬、编排软。
7. 观众在**手机横屏 0.38 倍**看 1080p。
8. 尺度 **36 / 40 / 48 / 96 / 144 / 224 / 320**。
9. **默认值做到极致，规则一条不加**。
10. 预设只准用 token + 机制。

## 9 · 实施顺序（垂直切片优先）

横向分层（先值、再度量、再姿态……）会让每一步都看不见画面变化。改成切片：

**切片 A（02 代码 / 09 内存 / 11 截图 三帧）**
值 → 度量 → 姿态 → 求值 → 预设，一条线打通，三帧达到目标；
**切片 B**：把打通的机制铺到其余 9 帧；
**切片 C**：M2 映射、M3 路由、M4 场与层、M7 文本补齐，并用新的帧验证。

每片结束都要有：可复核的数字 + 可看的帧 + 通过的 `vk check`。

## 10 · 验收

一帧算“成立”的条件（作者自负，库只报告）：

- 内容墨量 ≥ 安全区 8%；最大实心块 ≥ 安全区 12%（主角不是标题）；
- 相邻字号断层 ≥ 1.8×；字阶档数 ≤ 3；
- 焦点面积 1–4%，且唯一；
- 骨架与前后帧不同；
- 所有必须读的字 ≥ 48（或等宽 ≥40），对比度 ≥ 7:1。
