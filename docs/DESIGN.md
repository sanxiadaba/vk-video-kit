# vk v24 · 设计系统

这是库的**视觉契约**，不是模板，也不是分镜指南。
一帧 = 一张 1920×1080 的图；作者只写内容、`current`、`tone`、`theme`，其余由这一层决定。

## 1. 画布与版心

- 画布 1920×1080。
- 版心 1680×888：左右 120，上下 96。**对称**。
- 标题带、正文带都在这 1680 内；`bleed` 是唯一允许越出版心的能力。
- 不替任何播放器 UI 预留“安全区”。镜头裁切是外层视频的事。

## 2. 标题带

标题带由内容实测，不预留空 `lede`：

- 眉标 56，标题 144（`headline`）/ 96（`subhead`）/ 216（`display`），导语 64。
- 眉标→标题 24，标题→导语 24，标题带→正文 64。
- 带 lede 约 352 高；不带约 244；两行标题按实际行数增长。
- 标题默认 144。长标题、密集页显式用 `size="subhead"`，不要靠 144 硬换行。
- 需要断句用 `<br>`；不要让 `text-wrap: balance` 替你断在虚词后。

## 3. 正文带

- 正文在剩余区**垂直居中**；`place="top"` 才贴顶，`center` 只给封面。
- 正文高于剩余区超过 4px 时，整页按 `(正文带高 - 4) / 内容高` **连续缩放**，上限 0.96、下限 0.72，左上对齐；缩放后不再居中。
- 带 `vk-callout` 的页不缩：标注是页面坐标，缩放会把圈/引线和内容拆开。
- `vk-img[bleed=all]` 不缩：背景图不参与 fit。
- 短代码向上长到 96；长代码按宽/高缩到 40；代码行号 56，正文 64，行高 1.5；代码窗头是三点 + 64 的文件名。

## 4. 字号阶梯

| 角色 | 字号 | 行高 |
|---|---|---|
| 元信息 / 行号 / 注 | 56 | 1.5 |
| 正文 / 代码 / 表格 / 列表 / 图解节点 | 64 | 1.5 |
| 小节头 / 大数字 / 公式 | 96 | 1.35 |
| 帧标题 | 144 | 1.3 |
| 封面 | 216 | 1.2 |

- 正文行宽 25em；代码 / 图解按栏宽。
- 一个容器里最多两级字号；第三级用位置/颜色表达。
- 56 是地板；caption 只做标签、单位、行号、地址，不写整句。

## 5. 颜色与材质

- 纸 `#fff` / 暗面 `#0b0f14`；墨三档 `#111418 / #3f4652 / #5b6472`。
- 焦点钴蓝 `#1d4ed8`（暗 `#7aa2ff`）；暖黄 `#ffe58a` 只做 mark。
- 语法：keyword 深梅 / number 暖褐 / string 松绿 / comment 冷灰；已降饱和，焦点蓝仍最亮。
- 一帧最多一处钴蓝、一处暖黄。语义色只在线、图标、底标上。
- 材质：白纸、细线、无阴影、无渐变；窗口只有 4px 边、三点、64px 文件名。标注文字 64，结构线 6。

## 6. current

三种形态，按对象选一种：

- **行 / 表 / 列表**：12px 钴蓝左规，不加整行淡底。
- **格 / 节点 / 时间点 / 步骤**：4px 钴蓝描边或实心。
- **范围**（bytes / bits / dir 段）：淡底，表示一段而不是“当前行”。
- 同一帧只让一个东西成为焦点；圈选是黑色结构线，不抢蓝。

## 7. 排布

- `vk-flow` 默认按 `cols` 比例；两栏里一侧只有 ≤15 字批注、且主件是卡片/图片时自动堆叠。
- 代码窗、表格、卡片铺满栏；单件页不靠缩窄窗口留白。
- 三列表格固定 **32 / 38 / 30**；首列让出 32px 选中条。
- 表格数字列右对齐、tabular；表头 64；正文 64。
- 单件页内容少时居中，内容多时 fit；不靠加装饰填满。

## 8. 图解

- **graph**：节点最小 160，row 节点 200；图按可用宽高居中；边标签带 paper halo；两条以上不同边标签自动出图例，图例贴正文左缘，不贴图左缘。
- **seq**：泳道 7.14 / 92.86（2 条），3 条 7.14 / 50 / 92.86；行高统一 108；标签 64 在箭线上方，note 与标签同行；箭头 30，tip 落泳道内，箭杆退 10。
- **callout**：端口离边 10，箭尖缩进 4，箭头 32×16，拐角 16；ring 6px 黑结构线；measure 从格子中心量 pitch，标签是 64px 的 `4 字节` 票；note 是 64px 票，clamp 到正文底，不压字。
- **bits**：位格固定 80；**timeline**：轴线只画数据域；**bars**：条高 48；**steps**：圆 96。
- 画布高、节点、点、线宽来自同一套几何；不各写各的。

## 9. 合约与自检

- 20 个件，`src/schema.mjs` 是唯一契约；`vk brief` / `vk doc` 从它生成。
- 没有容量表、没有 `--advice` / `--strict`、没有留白/焦点/安全区评分。
- 自检只报 5 类：没有画布、渲染失败、资源失败、文字被裁/出界、锚点指空。
- 默认不拦出图；有问题也出 PNG，问题写进 `frame.json`；只有一帧都没出来才 exit 1。

## 10. 不做

- 不做模板、分镜、文案、配音、动画、视频渲染。
- 不替播放器/平台预留安全区。
- 不用门禁逼作者删内容；容量是作者判断。
- 不为了“高级”加纸纹、噪点、渐变、阴影、图标、圆角卡片。
- 不混用“技术手册页”语汇（宋体、去窗、单色语法）作为默认；那是可选方向，不是 v24 基线。
