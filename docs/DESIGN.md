# vk v25 · 设计系统

这是库的**视觉契约**，不是模板，也不是分镜指南。
一帧 = 一张 1920×1080 的图；作者只写内容、`current`、`tone`、`theme`，其余由这一层决定。

## 1. 画布与版心

- 画布 1920×1080。
- 版心 1680×888：左右 120，上下 96。**对称**。
- 标题带、正文带都在这 1680 内；`bleed="x"` 是唯一允许横向越出版心的能力。
- 不替任何播放器 UI 预留“安全区”。镜头裁切是外层视频的事。

## 2. 标题带

由内容实测，不预留空 `lede`：

- 眉标 56（行高 1.2），标题 144（`headline`）/ 96（`subhead`）/ 216（`display`），导语 64。
- 眉标→标题 24，标题→导语 24，标题带→正文 64。
- 带 lede 约 398 高；不带约 278；两行标题按实际行数增长。
- 标题默认 144。一行最多 **11 个字**（144×11 ≈ 1584 < 版心 1680）；超过就 `size="subhead"` 或显式 `<br>`。
- 需要断句用 `<br>`。

## 3. 正文带

- 正文在剩余区**垂直居中**；`place="top"` 贴顶，`center` 只给封面。
- **不缩放、不缩字**。内容高于正文带时贴顶对齐、溢到下边，体检单写「超出 N px」。
  - 没有 0.96–0.72 的整页缩放，也没有代码窗 40–84 的自动字号。
  - 之所以砍掉：手机 16px 的字没人看，而静默缩字会让 AI 把 8 行塞进 4 行的框。
- 有 `note` 的页，正文让出 480 注栏；注记是覆盖层，但它占的那一列是排版事实。

## 4. 字号阶梯

| 角色 | 字号 | 行高 |
|---|---|---|
| 元信息 / 行号 / 单位 | 56 | 1.5 |
| 正文 / 代码 / 表格 / 列表 / 图解节点 / 注 | 64 | 1.5 |
| 小节头 / 大数字 / 公式 / 代码窗文件名 | 96 | 1.35 |
| 帧标题 | 144 | 1.3 |
| 封面 | 216 | 1.2 |
| 封面（最大） | 300 | 1.1 |

- 正文行宽 25em；代码 / 图解按栏宽；注记在注栏里最多 408px（约 6 字一行）。
- 一个容器里最多两级字号；第三级用位置/颜色表达。
- 56 是地板；caption 只做标签、单位、行号、地址，不写整句。

## 5. 四个原语

所有件只是这四者的参数组合；改一处就全库生效。`src/state.css` 是唯一写「状态」的地方，
`src/components.css` 只写几何；两者在同一个 CSS layer 里，顺序固定。

| 原语 | 是什么 | 谁在用 |
|---|---|---|
| **面** surface | 底 + 6px 描边 + 圆角 + 内距（+ 可选标题栏） | `vk-card`、代码窗、目录、字节、位、内存格 |
| **行** row | 一条可带 `current` 的横排：左条 + 内容 + 右侧数值 | 代码行、diff 行、汇编行、表格行、列表项、目录行、时序行 |
| **线** connector | 8px 线 + 圆角折线 + 箭头（52×38） | 步骤、时间线、时序、关系图、标注 |
| **标注** annotation | 覆盖层：标记 / 连接 / 注记 / 量度 | `vk-callout` |

- `current` 只有两种渲染：**行**用 12px 钴蓝左规（asm 行 8px）；**盒**（格 / 时间点）用 6px 焦点描边，节点 6+6，步骤圈整块填充。
- `tone` 只发射 `--vk-tone` / `--vk-tint`，不直接写死颜色。
- `vk-card` 的 `tone` 只换描边 + 5% 淡底，一个字都不染色：对照靠边和位置，不靠红字。
- 标记按目标选形：词 / 块用 focus 色描边框，行用 14px 实心横条，行段用右侧括号；焦点蓝只给「正在看这里」。
- 关系图的边标签按**法线外推**到线上方，线不被字打断，字不压箭头。

## 6. 颜色与材质

- 纸 `#fff` / 暗面 `#0b0f14`；墨三档 `#111418 / #3f4652 / #5b6472`。
- 焦点钴蓝 `#1d4ed8`（暗 `#7aa2ff`）；暖黄 `#ffe58a` 只做 mark。
- 语法：keyword 深梅 / number 暖褐 / string 松绿 / comment 冷灰；已降饱和，焦点蓝仍最亮。
- 一帧只讲一处「正在看这里」；同一个故事里的节点和它的两条边可以一起变蓝。暖黄一处。语义色只在线、图标、底标上。
- 材质：白纸、细线、无阴影、无渐变；窗口只有 6px 边、三点、64px 文件名。
- **谁声明表面，谁写 `color-scheme`**：`vk-page[theme]`、`vk-card[surface]`；颜色 token 全部 `light-dark()`。

## 7. 线宽与圆角

| 档 | px | 手机（0.406×） | 用在哪 |
|---|---|---|---|
| hair | 6 | 2.4 | 卡片 / 窗口 / 表格横线 / 分隔 |
| connector | 8 | 3.3 | 连接线 / 箭头杆 |
| rule | 8 | 3.3 | 表头线 / 轴线 |
| strong | 12 | 4.9 | 当前行左规 / 焦点描边 |

圆角四档：`none 0 / sm 8 / md 12 / pill 999`。不加第五种。

### 连接件（唯一一套）
- 净空 12 / **箭头 52×38（长宽比 1.37，不是平底楔子）** / 尖端留 2 / 拐角 16 / 杆 8 / 有箭头的边最小间隙 88。
- 这组数只写在 `src/shared/connector.mjs`；CSS 通过生成的 `--vk-conn-*` 读同一组值，关系图、时序、标注共用。
- 布局可以用可用宽高算行距，但**不得小于 64**；放不下就减节点、减内距、把标题降到 `subhead`，不许把间距压没。
- 箭头尖端**压住**目标边（2px）；节点、边标签、箭头三者不许互相压。线走 0°/90°（直角折一次），不画 S 曲线；mesh 的两点直连除外。
- 竖链：盒子最小 480 宽、居中，箭头走盒子中线；链尾必须有 `null`/`∅`。

### 标注层（一次标注 = 一条标记 + 一条连接 + 一句话）

有 `note` 的页，正文右侧让出 480 的注栏（标题带不缩，仍整宽）。注记只住这一列：
永远不进卡片、不压代码。没有 `note` 的页，正文保持整宽。

| 件 | 常数（1920 / 780） | 规则 |
|---|---|---|
| 词 | 框：外扩 24 / 12，rx 8，线 12 | 套住整个 token（`a[i]` 连同 `[ ]`），不是单个字形 |
| 行 | 条：厚 14，离字 2，两头出头 10 | 墨迹下面一条；框会自造上边、和卡片同形 |
| 行段 | 右括号：竖杆 14 + 上下各 42 的脚 | 两行是一只括号，不是两条线 |
| 块 | 框：外扩 24 / 12，rx 8，线 12 | 闭合才说得清「这一块」，开线只能指「这里」 |
| 连接 | 杆 8，箭头 52×38 | 从标记右缘走到文字左缘；尖离文字 32，指盒子时才贴边 2 |
| 注记 | 64 / 26，行高 1.3，宽 ≤ 408 | 注栏里，和它指的那一行同高 |
| 量度 | 线 8、刻度 10、离目标 48 | 两条延长线落在两个目标的**同一条边**上 |
| 指针 | 52×38 | 两个件之间的有向连接；指文字时标签压在箭杆上（纸底把杆断开），指盒子时在杆上方 |

- 一帧一次标注：`mark` 只画标记，`note` 标记 + 一句；讲两件事就拆两帧。
- 形状跟着目标走，作者不选：词/块闭合，行开线，行段括号。**同一个意思，三种形状。**
- 标注一律 focus 色（钴蓝）——它和 `current` 是同一个意思：「正在看这里」；文字仍是墨色。
- 注记的 x 由注栏定，y 由它指的那一行定；作者只写 `for` 和一句话，不写坐标（锚点可以带 `@side` 提示方向）。

## 8. 图

- **graph**：节点最小 160；图按可用宽高排，超出正文带时**只压行距、不缩字**；边标签带 paper halo；两条以上不同边标签自动出图例。
- **seq**：泳道 7.14 / 92.86（2 条），3 条 7.14 / 50 / 92.86；一条消息 108 高；标签 64 在箭线上方，note 与标签同行；箭头用标注层的 52×38。
- **callout**：注记住注栏；行从行尾 +12 出线，词 / 块 / 行段从标记右缘出线；measure 量「同一条边到同一条边」。
- **bits**：位格 64；**timeline**：轴线只画数据域；**bars**：条高 48；**steps**：圆 96。
- 画布高、节点、点、线宽来自同一套几何；不各写各的。

## 9. 合约与自检

- 13 个标签，`src/schema.mjs` 是唯一契约；`vk brief` / `vk doc` / `docs/CONTRACT.md` 从它生成。
- 没有内置容量门禁、没有评分、没有 `--strict`（GUIDE 里的容量表是实测参考）。
- 自检只报五类硬错：没有画布、渲染失败、资源失败、文字被裁/出界、锚点指空。
- 默认不拦出图；有问题也出 PNG，问题与**事实**写进 JSON；只有一帧都没出来才 exit 1。

## 10. 不做

- 不做模板、分镜、文案、配音、动画、视频渲染。
- 不替播放器/平台预留安全区。
- 不用门禁逼作者删内容；容量是事实，不是判决。
- 不为了“高级”加纸纹、噪点、渐变、阴影、图标、圆角卡片。
- 不留旧名兼容层；v25 只有一套词。
