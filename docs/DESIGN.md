# vk · 设计系统（v27）

> 维护者文档，AI 写帧不用读。写帧看 [QUICK.md](QUICK.md)；数值以 `vk brief --facts`、`src/vocab.mjs`、`src/shared/connector.mjs` 为准。

## 1 画布与版心

- 画布 1920×1080；版心 1680×888（左右 120 / 上下 96，对称）。
- 手机横屏满屏 693（0.361×）；不替播放器 UI 预留。
- `bleed="x"` 是唯一横向越出版心的能力；`bleed="all"` 只给 page 第一层的 `vk-img`。
- 竖屏、镜头裁切不在这一层。

## 2 标题带与正文带

- 眉标 56 / 标题 144（subhead 96、display 216）/ 导语 64。
- 眉标→标题 24，标题→导语 24，标题带→正文 64。
- 带 lede 398 / 不带 278 / subhead 221；两行标题按实际行数长。
- 正文带：带 lede 426 / 不带 546 / subhead 603。
- 标题一行 11 字（144×11 ≈ 1584 < 1680）；用 `text-wrap: balance`。
- `place="band"` 标题带锁顶、正文在剩余区垂直居中；`top` 贴顶；`center` 整块居中（封面）。
- `band="lock"`：同一文件所有帧取最高那条标题带，视频不跳。
- 有 note 时正文让出 560 注栏；标题带不缩。

## 3 字号阶梯

| 档 | px | 行高 | 行宽（em） |
|---|---|---|---|
| caption | 56 | 1.5 | 26 |
| body | 64 | 1.5 | 25 |
| subhead | 96 | 1.35 | 17 |
| headline | 144 | 1.3 | 11 |
| display | 216 | 1.2 | 7 |
| hero | 300 | 1.1 | 5 |

- 56 是地板；caption 只做标签、单位、行号、地址。
- 693 下 64≈23、56≈20。行内 `code` 0.9em、`kbd` 0.875em。
- 一个容器最多两级字号；第三级用位置和颜色表达。

## 4 四个原语

| 原语 | 构成 | 谁用 |
|---|---|---|
| 面 | 底色 + 8px 描边 + 内距（+ 可选标题栏） | card、代码窗、目录、字节、内存格 |
| 行 | 12px 左规 + 内容 + 右侧数值 | 代码行、表格行、列表项、目录行、时序行 |
| 线 | 8px 杆 + 直角折一次 + 凹底箭头 52×38 | 步骤、时间线、时序、关系图、标注 |
| 标注 | 覆盖层：框 / 条 / 括号 / 箭头 / 量度 | `vk-callout` |

- `current` 只有两种：行用 12px 钴蓝左规（asm 8）；盒用 8px 焦点描边，步骤用整块填充。
- `tone` 只发射 `--vk-tone`，画在左规、描边、底标上；不染正文，不铺淡底。
- 强调只用几何与一个焦点色；没有图标，没有彩色装饰。

## 5 颜色与材质

- 纸 `#fff` / `#0b0f14`；raised `#fff` / `#1b2531`；soft `#f6f7f8` / `#121a24`。
- 墨 `#111418` / `#3f4652` / `#5b6472`（暗 `#f4f6f9` / `#c3ccd9` / `#9aa7b8`）。
- 焦点 `#1d4ed8` / `#7aa2ff`；mark `#ffe58a` / `#5c4614`。
- 结构线 `rgba(17,20,24,.42)` / `rgba(255,255,255,.44)`；强线 `.55` / `.62`。
- 语义 info / ok / warn / err 只上线、描边、底标，不写正文。
- 语法：string 松绿、comment 冷灰、number 青铜、keyword 莓红、operator 灰、fn 墨；按 paper ≥4.5:1 校准；蓝只表示「正在看这里」。
- 无淡底填色、无 mac 彩点、无图标；窗口只有 8px 边加标题文字。
- 材质：白纸、细线、无阴影、无渐变、无纸纹噪点。

## 6 线宽与圆角

- 线宽：hair 8 / connector 8 / rule 8 / strong 12；手机 2.9 / 2.9 / 2.9 / 4.3。
- 圆角只有 0：卡片、窗口、表格、标注框、内存格、徽标一律方角。
- 步骤序号仍是圆章，不是圆角矩形；除此之外没有例外。
- 12 用于当前行左规（asm 8）与盒焦点描边。

## 7 连接件几何

- 杆 8 / 头长 52 / 头底 38 / 凹底 18 / 尖端留 2 / 到文字 32 / 出线净空 12 / 最短跑道 24 / 拐角 16。
- 端口按外法线出线；线走 0°/90°，只折一次；不画 S 曲线。
- 箭头尖端压目标边 2；节点、边标签、箭头不互相压。
- 边标签按法线外推，带 paper halo；两种以上标签自动出图例。
- 图放不下只压行距，不小于 64；不缩字。
- 这组数只在 `src/shared/connector.mjs`；CSS 读生成的 `--vk-conn-*`。

## 8 标注层

- 有 note 的页正文让出 560；注栏 ≤440；无 note 整宽。
- 词 / 块框：外扩 16 / 12，线 12，零圆角。
- 行：实心条 12，离字 8，两头出头 10。
- 行段 / 项段：右括号 40，脚 32。
- 连接：杆 8 + 52×38 箭头；从标记右缘走到注栏。
- 量度：线 8，刻度 10，离目标 48。
- 指针：52×38；标签在杆上方、靠近源件。
- `jump`：同一代码窗的行到行，通道在窗右缘外 32，每条 +16，最多 3 条。
- 指针徽标 96 高，针脚 56；内存格 `ptr` 指到格上边。
- 注记 64 / 行高 1.3；x 由注栏、y 由目标行；多行对齐第一行；右侧会穿块时转目标上 / 下。
- 标注一律焦点色，文字墨色：词 / 块闭合框，行开线，行段括号。

## 9 各件几何

- code：窗口头 80；正文 64 / 1.5；行号槽 `位数×0.62em+24`；内距 8；半栏默认 caption。
- asm：地址列 88，`addr=off` 省；`hex` 才有机器码列；助记符 2.8em。
- list：行高 96；current 左规 12。
- steps：圆 96；容器窄于 760 自动竖排。
- bars：条高 48；值只写数字，单位走 `unit`。
- timeline：方块节点 40（current 48）+ 连续轴，轴只画数据域；日期到节点有 8px 刻度。
- table：数据行约 103；数字列右对齐、等宽；表题用原生 `<caption>`。
- cells：全宽一格约 354；半栏 2×2：值 64、标签 / 地址 56；`ptr` 加 152，别进 2×2。
- band：一条轴，段按 `start` / `end` 比例；`lane` 分泳道。
- frames：一帧一行，一帧 2–3 个字段；向低地址生长时轴反过来。
- graph：节点最小 160；`row` 不换行；按可用宽高排，只压行距。
- seq：2 条泳道 7.14 / 92.86；3 条 7.14 / 50 / 92.86；一条消息 108；标签 64。
- dir：行高 1.5em；缩进 40/层；树线 `line-strong`；current 竖条贴缩进。
- bytes：地址 + 十六进制 + ASCII；`cols` 默认 8。
- bits：位格 80；一段一条底线；`index` weight/order/none/sparse；`sign` 标符号位。
- math：构建期 KaTeX；行内 inline。

## 10 主题规则

- 谁声明表面谁写 `color-scheme`：`vk-page theme`、`vk-card surface`。
- 颜色 token 全部 `light-dark()`；嵌套面自动取明暗。
- `surface="auto"`：浅页 paper、暗页 raised；paper / soft / raised 是显式材质。
- 深色页最多一块 paper。
- 暗面层次：page `#0b0f14` / soft `#121a24` / raised `#1b2531`。

## 11 不做

- 分镜、文案、配音、动画、视频。
- 播放器安全区。
- 自动缩字。
- 圆角、阴影、渐变、纸纹、噪点、图标、淡底填色、mac 彩点。
- 旧 API 兼容层。
