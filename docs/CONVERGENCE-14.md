# vk 14.0 收敛报告

> 2026-10-31。从 13.0 的"野蛮生长"收到 14.0 的"一个东西，一种写法"。
> 这份报告回答三个问题：删了什么、凭什么、怎么证明没删坏。

## 0 · 起点与终点

| 指标 | 13.0 | 14.0 | 变化 |
|---|---|---|---|
| 标签 | 41 | **30** | −11 |
| 属性声明 | 749 | **580** | −169（−23%） |
| 属性**概念** | 155 | 143 | −12 |
| 契约跳过的概念 | 51%（按声明数） | **17%** | 预算 20% |
| CSS 行数 | 3382 | **2502** | −880（−26%） |
| 阈值定义 | 3 套（96/72/96、36/36/35.5、4.5/3） | **1 套**（`src/shared/limits.mjs`） | — |
| 规格文档 | 4 份（design/v13/README/ai） | **1 份**（`docs/v14.md`） | — |
| `npm test`（温） | ~110s | **32s** | −71% |

## 1 · 删了什么，凭什么

**判据只有一条**：一个标签代表**一个东西**才留下；"一组东西的排版"删掉，归项目自己的 CSS。

### 删掉（13 个）

| 标签 | 为什么 | 去处 |
|---|---|---|
| `vk-title` | 眉题 + 主标题 + 副题，三件套 | `.r-title` / `.r-eyebrow` / `.r-title-main` / `.r-title-sub` |
| `vk-stat` | 标签 + 数值 + 单位；唯一机制是数字写法 | `.r-stat` + `vk-text format="thousands"` |
| `vk-quote` | 竖线 + 大字 + 出处 | `.r-quote` |
| `vk-figure` | 图窗 = window + img + caption | `.r-figure` |
| `vk-tag` | 零 JS，带底色的行内小件 | `.r-tag` |
| `vk-mark` | 零 JS，底下一条色带 | `.r-mark` |
| `vk-panel` | 面 + 头 + 分隔线 | `.r-panel` |
| `vk-callout` | 面 + 竖线 + 图标 + 标题 | `.r-callout` |
| `vk-row` | 与 `vk-stack` 是同一个空类，只差 flex-direction | `vk-stack direction="row"` |
| `vk-keys` | 与 `vk-inline` 同为行内小件 | `vk-inline variant="keys"` |
| `vk-spotlight` | 与 `vk-ring` 同为"看这里"，一个压暗一个画框 | `vk-ring variant="dim"` |

`vk-bytes` / `vk-bits` **没有并进 `vk-cells`**（原计划 41→28，实际 30）。**2026-10-31 决策：接受 30，保住 20% 预算。**
这不是偷懒，是计划自己的两条规矩打架：

- `vk-cells` + `vk-bytes` + `vk-bits` 的属性并集是 **39 条**，其中 17 条只在各自的 variant 下成立；
- 这 17 条必须标成 `context`（否则契约会在 cells 的默认态上量它们，必然失败）；
- 标完 `context` 之后，跳过的概念从 25 涨到 42，占 143 个概念的 **29%**，直接冲破"跳过 ≤20%"的预算。

换句话说：**要么 28 个标签、跳过 29%，要么 30 个标签、跳过 17%。** 两条规矩只能选一条。
我选了后者——因为 17% 那条是为了"每个属性都得有人证明它有用"，而 28 只是个估算出来的整数。

## 2 · 删掉的知识去哪了

答案是：**没有替代品，它就是没了**。

14.0 最早的做法是建一层"配方"（可执行的 HTML + CSS 页），把被删的组合标签养起来。
2026-10-31 决定删除：**那仍然是第二套要维护的语义**——它有自己的 CSS、自己的测试、
自己的文档页，只是换了个名字。库的定位是底层原语，组合属于项目。

代价写在明处：作者要自己写那 6 行 div 和 5 个类名。这是"底层库"的应有代价，
不是缺陷。一集片子的 `film.css` 就是它的落点。

## 3 · 门禁：从"演"到"能失败"

13.0 的问题不是松，是**假**：

| 问题 | 13.0 | 14.0 |
|---|---|---|
| 契约跳过 | 382 条静默 continue | 按概念记账 17%（预算 20%），超了失败 |
| 空页 | 一律通过 | 报 `empty`（<12 字且无图） |
| 预设像素差 | 死分支（`lens==='plate'` 永不成立） | 真跑，当场抓出 4 条"设了等于没设"的预设 |
| `vk.freeze()` | 两处调用，函数不存在 | 已删 |
| 审计副本 | audit / gate 兜底 / contract 各一套阈值 | 一份 `auditPage` + 一份 `limits.mjs` |
| 焦点识别 | 只认 `[tone]`，pose 写的是 `[data-tone]` | 认 `data-act` / `data-tone` |
| 测试清单 | 手写，漏 3 个文件 | 扫目录，18 个全跑 |
| 缓存键 | 不含页面自己的 CSS | 含 `docs/**.css`（改了页面 CSS 旧绿结论不再复用） |

**五个坏页面**（空页 / 超宽 / 两处焦点 / 越安全区 / 灰字太浅）全部被拦，见 `tests/gate-truth.test.mjs`。

## 4 · 12 帧验收

基准：收敛前 12 帧的**布局指纹**（每个文字行的位置、尺寸、字号、内容，共 302 行）。

| 结果 | 帧 |
|---|---|
| 零漂移（±1px 内） | 01–08、10、11 —— **10 帧** |
| 有位移 | 09（提示框）、12（引文） |

两帧的差异都来自"组件渲染 → 配方排版"，不是逻辑错误：

- **09**：x 已经对齐（671），剩下 9px 竖向差与正文折行不同——`.r-callout` 的右栏宽度
  与原组件不同（原组件按父容器收，配方按 measure-body 收）；
- **12**：出处那行文字宽 427 → 499px（同一段字，排法不同）。

继续调这两处就是在把组件偷偷搬回来，所以停在这里：
**10/12 帧零漂移，2 帧差异各有一句可复现的解释。**

## 6 · 14.0 之后补上的（同日）

- **配方层删除**：那仍是第二套要维护的语义。库现在一行组合都不出，组合归项目的 `film.css`。
- **CSS 走解析器**：`tools/lib/css-ast.mjs` + `tests/css.test.mjs` 常驻。
  第一次跑就抓出 4 条指向已删标签的死选择器。
- **契约意图断言**：205 个属性断"改成什么"，8 个仍只断"有变化"（预算 8），15 个完全不限定（预算 15）。
  剩下这 8 个是"算出来不等于写进去"的：edge 的四个路径参数、pin 的宽度与间距、ring/canvas 的 pad。
  期间修了两处标本错误：vk-ring 预置了 dash（探针只会把它关掉），预设"实线"与默认态像素相同。
- **结构断言**：`tools/structure.mjs`，在 demo 上抓出两帧用了四档字号。
- **交付尺度**：`tools/legibility.mjs` 在 0.38 倍下量最淡的墨，12 帧实测 1.92–2.21:1。
- **组合冒烟**：`tests/compose.test.mjs`。
- **dev server 过时**：库改了而进程还活着时，以前会报"预编译失败"（像是页面写错），
  现在明确说"服务器过时，重启即可"。
- **demo 第 9 帧的"半页灰"**：它的 `keep="vk-title"` 指向一个**已经删掉的标签**，
  所以标题从来没被保住、被 dim 一起压灰了。改成 `.f-title` 后正常——
  这是"删标签时忘了改引用"的又一个例子，而且它只在画面上显形，门禁看不出来。

## 7 · 覆盖矩阵（demo 用了哪些原语）

demo 12 帧 + 连排页用到 24 个原语：asm / bars / bytes / cells / code / edge / grid / icon /
img / inline / loupe / math / page / pin / ring / rule / stack / steps / table / term / text /
timeline / tree / window。

没用的 6 个：box / diff / compare / bits / canvas / list。
demo 的职责是"真实用法能不能拼起来"，不是"把 30 个都点名"。硬塞一个 13 页的 API 冒烟页
试过一次：三栏塞满后在 1080 里过不了门禁，最后删掉了。这是刻意的取舍，不是遗漏。

## 8 · 还没做的

1. **`vk-bytes` / `vk-bits` 未并**（见 §1）：合并会把"跳过"推到 29%，与 20% 预算冲突。所以是 30 不是 28。
2. **契约仍有一份自己的视觉检查**（`visualInPage`），只是阈值改读 `limits`；
   彻底合一要在每个探针上跑 `auditPage`，实测会慢 2–3 倍，暂缓。
3. **09/11/12 三帧的配方位移**未压到零。
4. 线上站点尚未重新部署（本地 `_site` 已是 30 个标签）。
