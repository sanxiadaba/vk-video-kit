# vk 14.0 · 一个东西，一种写法

> 这份文件是 14.0 的**唯一规格**。`design.md` 已删除（它写的"没有动效、没有时间轴"从 13.0 起就不成立）；
> `v13.md` 已被本文件取代。

## 0 · 身份

一个视频制作环节里的**画面原语层**。它不决定讲什么、不决定怎么排、不决定节奏；
它保证：任何一帧里出现的物，都在正确的时刻、以正确的姿态、被正确地测量。

**准入判据（唯一一条）**：一个标签保留，当且仅当它代表**一个东西**。
"一组东西的排版"不配拥有标签，**也不该由库提供**——它是项目自己的 CSS。

判据的用法：`box` 是一个东西，`panel`（面 + 头 + 分隔线）是一组排版 → 删；
`edge` 是一条关系，`pin`（气泡 + 引线 + 编号）也是关系 → 留；
`title`（眉题 + 主标题 + 副题）是一组排版 → 删。

## 1 · 四层

| 层 | 内容 | 谁写 |
|---|---|---|
| **值 tokens** | 尺度梯、间距角色、线宽、明度面、色相、行高、缓动、时基 | 库作者 |
| **原语 primitives** | text / inline / icon / img / rule / box / window | 作者直接用 |
| **机制 mechanisms** | 排布、数据、解析、关系、求值 | 作者用属性调用 |

## 2 · 30 个标签（14.1 起 31）

- **原子（6）**：`text` `inline` `icon` `img` `rule` `box`
- **外壳（1）**：`window`
- **布局（4）**：`stack` `grid` `canvas` `page`
- **数据（6）**：`table` `cells` `bars` `steps` `timeline` `list`
- **解析（5）**：`code` `asm` `term` `diff` `tree`
- **公式（1）**：`math`
- **关系（5）**：`edge` `ring` `pin` `loupe` `compare`

14.0 删掉的 11 个：`title` `stat` `quote` `figure` `tag` `mark` `panel` `callout`（→ 项目自己的 CSS）、
`row` `keys` `spotlight` `bytes` `bits`（→ 并进 `stack` / `inline` / `ring` / `cells`）。

> **14.1（批次 A）加回 `vk-panel`**：不是 14.0 删掉的那个三槽卡片，而是「底色 + 可选标题带 + 内距 + 圆角」
> 的语义分区（`tone` × `variant`）。标签数 30 → 31；旧 `panel` 的 `slot` / `n` / `elevation` 不再存在。

**`vk-compare` 的 split 语义**：`split` 表示"左边 split% 显示 `a`、右边显示 `b`"；
`a` 在左、`b` 在右，和左下角标 `label-a`、右下角标 `label-b` 一一对应。行为按这个口径走，不反过来。

## 3 · 组合不归库

指标、标题三件套、引文、图窗、胶囊、荧光笔、提示、卡片——这些都是"一组东西的排版"，
**库不提供，也不打算提供**。它们是项目自己的 CSS（通常一个 `film.css`），
因为一集片子怎么讲，决定了它们长什么样。

库能提供的只有：31 个原语 + 令牌 + 一套门禁。作者用它们拼；拼得对不对，由门禁而不是由库管。

## 4 · 两条协议

**坐标**：`x / y / z / span / row-span` 只在 `grid` / `canvas` 的子节点上成立。
写在别处运行期会警告——它不是标签属性，是父容器的协议。

**注意力**：`act`（做什么）× `strength`（多大声）两个维度，声明在基类上，只有一处。
运行期把它们落成 `data-act` / `data-strength` / `data-tone`，CSS 只认这三个来源。

| act | 语义 | 落法 |
|---|---|---|
| `focus` | 现在讲这里 | 行：`data-state="current"`；块：钴蓝 ink（`data-tone`） |
| `context` | 其余退后 | 兄弟 `opacity` 降到 dim |
| `mark` | 作者标注 | 石墨，永不用钴蓝 |
| `trace` / `badge` / `compare` | 线 / 批注 / 对照 | 由 `edge` / `pin` / `compare` 自带 |

## 5 · 时间在求值器

组件只承诺「任一稳定姿态成立」。作者写 `at` / `enter` / `stagger` / `dur` / `poster`；
`seek(t)` 是纯函数，只动 `transform / opacity / clip-path / stroke-dashoffset`。
`poster`（默认 t=end）必须逐像素等于不带动画的静态页。
不提供播放器、不提供转场、不提供时间轴 UI；构建产物里不出现 `animation:` / `transition:`。

## 6 · 观看条件与数值（唯一来源：`src/shared/limits.mjs`）

1080p 出片，观众手机横屏看：真实缩放 0.36–0.40，设计按 **0.38**。

| 角色 | 设计 px | @0.38 |
|---|---|---|
| 标签 / 行号 / 刻度 | 36 | 13.7 |
| 等宽数据 | 40 | 15.2 |
| 正文 | 48 | 18.2 |
| 小标题 | 96 | 36.5 |
| 页标题 | 144 | 54.7 |
| 数字主角 | 224 | 85 |
| 一个词当家 | 320 | 122 |

**对比度分三档**（不是一刀切）：

| 角色 | 门槛 | 为什么 |
|---|---|---|
| 正文 / 主墨 | **7:1** | 0.38× 下要读懂的那一句 |
| 标注 `ink="muted"` / `[data-meta]` | **4.5:1** | 不承载必要信息，压到 7 会让灰变黑、层级消失 |
| 等宽数据区（代码 / 地址 / 位） | **4.5:1** | 颜色在这里是编码（字符串/运算符/地址），全压 7 会变成一片深灰 |

线宽两档：发丝 2px、结构 4px。字重反过来用：≤40 用 500，≥144 用 600。

## 7 · 门禁

只有一份审计（`src/runtime/audit.mjs` 的 `auditPage`），只有一份阈值（`limits.mjs`）。
`vk check` / `npm run gate` / 契约的视觉检查读同一套数。

- **硬失败**：字号地板、正文档位、对比度分档、安全区、裁切、重叠、空锚点、空帧、焦点唯一。
- **提醒**：底部空带、孤行、焦点蓝面积。
- **契约**：每个公开属性改一个取值。14.0 起分成两类——
  **断"改成什么"**（`expect`：focus 必须是钴蓝、grow 必须 flex-grow:1、mono 必须是等宽字体）与
  **只断"有变化"**（有预算，只许往下调）。被跳过的属性按"概念"记账，预算 20%。
- **结构**：`tools/structure.mjs` 量每帧是否成立——主角面积、字号档数（≤3）、焦点数（≤1）、
  墨量、底部空带。像素指纹只证明"和上次一样"，结构断言证明"这一帧是对的"。
- **交付尺度**：`tools/legibility.mjs` 把 1920×1080 缩到 0.38 再量最淡的墨。
  设计尺度的 7:1 不等于屏幕上的 7:1——2px 的线缩完只剩 0.76 个设备像素。
- **组合**：`tests/compose.test.mjs` 把十几个物拼成一帧跑审计。标本页只证明"单个成立"，
  覆盖层压住正文、grid 抢宽度这类问题只有拼起来才看得见。

五个坏页面（空页 / 超宽 / 两处焦点 / 越安全区 / 灰字太浅）必须全被拦，见 `tests/gate-truth.test.mjs`。

## 8 · 输出契约

```
vk shot scene.html --at 2.4 --out frame@2.4.png          # 单帧
vk shot --batch a.html b.html --out-dir shots/            # 一组单帧（一个浏览器）
vk shot scene.html --fps 30 --range 0-4.6 --out-dir film/09 # 帧序列
vk shot scene.html --scene --out scenes/09.json           # 时间表
```

时间表 = 每个 cue 的 `{ t0, dur, ease, target, pose, props }`。
**库不碰编码、帧率合成、音画同步。**

## 9 · 十条决定（2026-10-30 起，14.0 复核）

1. 单位是**镜头**，可彻底重构；标签数不神圣（41 → 30）。
2. 库**不排片**：不求解版式、不出帧型、不规定节奏。
3. 时间在求值器，组件只出姿态。
4. 注意力只有一套词汇（act × strength），只有一个实现。
5. 身份是**机制优先**；组合不归库。
6. 门禁**分层**：语义硬、编排软；数值单源。
7. 观众在**手机横屏 0.38 倍**看 1080p。
8. 尺度 **36 / 40 / 48 / 96 / 144 / 224 / 320**。
9. **默认值做到极致，规则一条不加**。
10. 预设只准用 token + 机制；"一组东西的排版"离开库，归项目。
