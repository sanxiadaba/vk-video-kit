# 规则（判断类的都在这）

数字与取值不在这里抄一遍：见 `CONTRACT.md` 或 `vk doc <tag>`。

## 一、一帧的容量

版心 888 高。一个标题块（label 64 + gap 32 + subhead 120 + gap 32）约 248，剩下 **640**。
640 约等于 **8 个行级单元**：

| 件 | 一帧最多 | 备注 |
|---|---|---|
| `vk-code` / `vk-diff` / `vk-asm` | 8 行 | 再多会缩到 44px 地板，然后被裁（自检会报） |
| `vk-term` | 10 行 | 终端行高比代码小 |
| `vk-table` | 5 行 | 表头另算 |
| `vk-tree` | 10 行 | 超了末尾留一行「…还有更多」 |
| `vk-cells` | 2 行 | `cols=4` 时 8 格 |
| `vk-steps` | 5 步 | 横排；再长换 `direction="vertical"` |
| `vk-bars` | 6 条 | |
| `vk-timeline` | 4 点 | |
| `vk-bits` | 16 位 | 32 位要 `index="sparse"` 才数得清 |

**一帧 = 1 个主件 + 1 句结论。** 两个数据件（代码 + 表格）基本一定超。

## 二、选件

| 要讲的东西 | 用 |
|---|---|
| 真实源码 / 终端 / diff / 汇编 | `code` / `term` / `diff` / `asm` |
| 内存、字节、位 | `cells` / `bytes` / `bits` |
| 结构（表、要点、目录） | `table` / `list` / `tree` |
| 关系（先后、量级、时间、对照） | `steps` / `bars` / `timeline` / `pair` / `compare` |
| 版面（面、字、标签、图） | `box` / `text` / `label` / `img` |
| 指着某处说一句 | `callout` |
| 只能按坐标摆 | `canvas`（逃生口，能不用就不用） |

两条容易选错的：

- **横向排**用 `vk-stack direction="row"`；**分栏/按 12 栏**用 `vk-grid`；**两块对照**用 `vk-pair`。
- `vk-list` 是文字要点，`vk-table` 是二维对齐，`vk-tree` 是缩进层级：读者做的是三件事，别互换。

## 三、颜色

- 三档墨：`ink="primary"`（正文）/ `secondary`（次要）/ `muted`（元信息）。正文只用 primary。
- **一个焦点色**（钴蓝）：只在「正在讲这里」时出现。一帧最多一处，否则等于没有焦点。
- 四个语义色 `info / ok / warn / err`：只出现在线、图标、底标上，**不写正文**。
- 正文要强调用 `<em>`（一条焦点色下划线）或 `<mark>`（淡底），不要用 `tone` 上色。
- `tone` 与 `state` 分工：对错用 `tone`，注意力用 `state`。

## 四、深色页

- 整帧反白：`<vk-page surface="dark">`。墨、线、语义色、淡底、语法色一起换。
- 深色页上放纸面件（代码窗、卡片、内存格）**自动**保持白纸黑字：每个件自己声明表面，
  嵌套几层都对，不用手动改 `ink`。
- 一集用一帧深色收尾是个好习惯，但不是库的规定。
- 终端默认就是深色窗；`chrome="none"` 去掉窗头，就是一张「整帧终端」。

## 五、铺满与出血

- `bleed="x"`：横向出血到画布边（不动兄弟）。
- `bleed="all"`：只给 `vk-img`，整帧铺满当底，内容自动压在它上面。
- 图上的字必须落在实底上（`vk-box surface="paper"`）。库不提供遮罩。
- **没有 `bleed="y"`**：纵向出血会拉动兄弟，做不到「只影响自己」。

## 六、锚点与索引

- 全部 **1 起**：`current`、`@cell`、`@byte`、`@bit`、`@step`、`@event` 都一样。
- `@line` 按**源文件**算，不是窗口里显示的第五行。`lines="10-14"` 的窗口里，`@line:13` 指源文件第 13 行。
- `for / from / to` 收 CSS 选择器或 `#id@part:arg`：`line / word / cell / byte / bit / addr / step / event / lane / node / point / side / region`。
- 圈选按**字的墨迹**取框：`#c@line:5` 圈的是那一行字，不是 1680 宽的行盒。

## 七、自检判什么

只有五类，都是「无论怎么画都错」：

1. 这一页没有 `<vk-page>`，或画布不是 1920×1080
2. 件自己渲染失败 / 缺预编译数据
3. 资源加载失败（图片、字体、脚本）
4. **文字被裁**（横向或纵向，含祖先的 overflow）
5. 标注指向空气

其余（留白、重叠、焦点数、对比度、密度）**不判**：那是默认值和你的判断。
`vk render` 会顺手打一行「墨迹 y 96–410（占版心 35%）· 焦点 1」，用来对比相邻帧。

## 八、什么时候拆帧

出现下面任何一条，就是这一帧讲多了：

- 内容超过 888（`vk render` 会说超多少）
- 代码超过 8 行，或者要写 `size="caption"` 才塞得下
- 一帧里出现两个 `current`（观众不知道看哪）
- 标题从 `subhead` 降到了 `body`
- 你要靠 `vk-canvas` 手摆坐标才能放下
