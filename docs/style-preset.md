# 项目层审美 preset（默认关）

> **这不是库的要求。** 库只判客观错误；下面六条是「这一集 / 这一册」的版面主张，
> 换个项目就该重定。它们默认**不跑**，只有显式打开才会出现。

## 库判什么，项目判什么

| 库（默认，永远是错误） | 项目（preset，默认关） |
|---|---|
| 溢出画布 / 容器、内容被裁 | 强调色 ≤ 1 |
| 覆盖层压住正文 | 深色块 ≤ 1 |
| 非法枚举 / 越界数字 / 未知属性 | 页眉只讲工序（不含文件名 / 页号） |
| 锚点解析失败、空锚点 | 内容落在 120 边距内 |
| 组件渲染失败、空组件、`data-vk-stale` | 字幕短句：不带句号、每行 ≤18 字（提醒） |
| 素材哈希不符、运行崩溃 | （图标白名单：提醒，不是错误） |

「一页只有一个答案」「一页只砸一块重」这类话是对的，但它们是**版面观**，不是
组件能不能用的条件。把它们写进库的默认路径，结果是：作者为了过审计去删内容，
而不是把内容讲清楚。15.x 把它们移出 `src/runtime/audit.mjs`，收进
`src/runtime/style-preset.mjs`。

## 怎么开

```bash
# 1) CLI：在普通自检之外，多跑这六条
node bin/vk.mjs check frames/06.html --style

# 2) 独立入口（同一个 preset，带规则清单）
node tools/style-preset.mjs frames/06.html
node tools/style-preset.mjs --list
```

运行期也直接可调：

```js
window.vk.auditPage(document, { style: true }); // 默认 { style: false }
window.vk.auditStyle(document);                 // 只跑这六条
```

`STYLE_RULES`（`src/runtime/style-preset.mjs`）是唯一清单：CLI、施工脚本、
测试、文档都读它，不各自抄文案。

## 六条规则

| 规则 id | level | 判定 | 为什么它是项目层的 |
|---|---|---|---|
| `accent` | error | `tone="focus"` 的答案级元素（`vk-text` / `vk-panel`）超过 1 处 | 「一页只有一个答案」是叙事密度，不是组件的属性 |
| `dark` | error | 底色亮度 < 0.05、面积 ≥ 160×60 的区域超过 1 块 | 「一页只砸一块重」是构图 |
| `icon` | **warn** | `vk-icon` 的名字不在语义白名单里 | 装饰图标可以留；只是提醒「知道自己在用装饰」 |
| `header` | error | `kicker` 里出现文件名（`.c` / `.s` / `.exe` …）或「第 N 页 / N 帧」 | 页眉写什么取决于这一集的工序划分 |
| `margin` | error | 交付页里有可见内容越出 120 边距（覆盖层 / 出血层豁免） | 120 是这一集的交付边距，可以换 |
| `copy` | **warn** | 字幕位（`vk-text size="caption"` / `vk-caption`）以句号收尾，或一行超过 18 字 | 视频字幕的句长与标点是这一集的文案规矩，不是组件约束 |

`copy` 只判**字幕位**，不判正文段落：body / headline 仍可写完整句子。
默认不启用，与其他五条一样只在 `--style` 下给出提醒（level=warn）。
项目层的写法参考 `film.css`：字幕短句——不带句号、每行 ≤18 字、不用「。」结句。

图标白名单在**构建期也只提醒**：`vk build` 打印一句「不在语义图标白名单里」，
不拦构建。运行期要再看一遍就加 `--style`。

## 和 `vk-legacy` 的关系

`<body class="vk-legacy">` 是**尺寸**开关：它把 15.x 的
200 / 112 / 56 / 48 与窗头 56 / 72 / 88 切回 14.x 的
160 / 96 / 40 / 28 与 40 / 56 / 72，审计的地板跟着切回 28 / 40 / 96。
它**不会**打开或关闭这个 preset —— 审美判断和尺寸是两件事。

迁移期建议：旧页先加 `vk-legacy` 保持逐像素不变；重做某一页时去掉它，
按新基准排版，再决定要不要用 `--style` 收一遍版面。
